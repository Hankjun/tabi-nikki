# 旅日記 · Tabi Nikki

复刻自用户提供的 Claude Artifact，保留原始页面样式、照片、视频、插画与字体。

## 本地使用

双击「启动旅行日记.command」恢复本地网站，然后打开 http://127.0.0.1:4173/ 。服务独立于当前聊天运行，重启电脑后需再次双击启动。

开发时可运行 `npm run dev`；`npm run build` 生成静态网站。从源码压缩包首次使用时，先安装依赖 `npm install` 并构建。

## 功能

照片大图与键盘/触屏翻页、视频播放及静音、路线横向滚动、美食印章、鸭子对话、返回顶部、便签新增/配色/删除。

便签和盖章保存在当前浏览器，不需要 Claude 登录，不提供跨用户同步。清除浏览器站点数据会清除记录。
